# Support

APEIR Distribution is a community-maintained open-source project. The current
working tree is an engineering candidate provided for evaluation and
integration testing without a commercial support or response-time commitment.

## Before opening an issue

1. Run `apeir doctor`, `apeir status`, and `apeir models doctor`. The legacy
   `nous` command remains available during the compatibility window.
2. Review the [user documentation](docs/user/README.md),
  [troubleshooting guide](docs/user/getting-started/TROUBLESHOOTING.md), and
  [known limitations](docs/release/KNOWN_LIMITATIONS.md).
3. Search existing issues.

For a reproducible non-security defect, include the APEIR version, operating
system, Python version, installation method, steps, expected result, actual
result, and redacted diagnostics.

Never post credentials, private paths, prompts, conversation content, device
identities, Runtime state, or vulnerability details in a public issue. Follow
[SECURITY.md](SECURITY.md) for private security reporting.
