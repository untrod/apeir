Historical generated Pack scaffold, retained for compatibility and comparison.
It imports an internal legacy Provider type and declares a `runtime` dependency
which is not a current Pack dependency ID. Its generated relative test import
is not the current public SDK example. Do not use its old installation/test
commands as Developer Preview instructions.

For a runnable adapter, use [Hello Provider](../examples/hello_provider/README.md).
For reviewed Pack metadata and permission boundaries, use the
[Pack guide](../docs/development/PACK_DEVELOPMENT.md). The original manifest,
source and tests remain unchanged; this page supplies no execution permission.
