# Runtime boundary

The authoritative boundary is the
[project constitution and Distribution boundary](DISTRIBUTION.md).
[Execution Path](EXECUTION_PATH.md) distinguishes Kernel-managed NKI workloads
from governed Distribution runtime-service operations.

Domain goals, knowledge, prompts and industry workflows are client/Provider
inputs. They do not alter authority, Work lifecycle, evidence requirements or
failure semantics. Generic runtime contracts must remain hardware- and
intelligence-neutral. Historical study/exam migration notes do not define an
additional kernel or execution system.
