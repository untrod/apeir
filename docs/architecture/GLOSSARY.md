# Nous Glossary

| Term | Definition |
|------|-----------|
| **Brain** | The Nous server running on your hardware |
| **Capability** | A named action: `model.reason`, `device.pc.shell` |
| **Provider** | Backend that executes capabilities: GPT, PC Agent, ESP32 |
| **Module** | Business logic grouping: Learning, Capture, Notification |
| **NKP** | Nous Kernel Protocol — apps <-> brain |
| **NEP** | Nous Edge Protocol — devices <-> brain |
| **NFP** | Nous Federation Protocol — brain <-> brain |
| **NSP** | Nous Skill Protocol — 3rd-party developer interface |
| **Observer** | Post-execution verification layer |
| **Reasoning Trace** | Decision chain: WHY each choice was made |
| **Risk Gate** | LOW->auto, MEDIUM->audit, HIGH->confirm, CRITICAL->revoke |
| **Envelope** | Unified message format for all protocols |
| **Demo Mode** | `NOUS_DEMO_MODE=1` — run without real models or devices |
