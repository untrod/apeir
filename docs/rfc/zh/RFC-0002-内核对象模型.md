# RFC-0002: Nous 内核对象模型

- **状态:** 草案 | **日期:** 2026-08-04

## 问题

当前有三个不兼容的 Task 模型、22+ 个独立 Registry、没有 Spec/Status 分离。

## 核心对象

Principal, Namespace, Workspace, Workload, ExecutionGraph, Phase, Task, Run, ModelPackage, ModelRevision, Engine, Device, Node, Capability, ResourceDomain, ResourceRequest, ResourceLease, TensorObject, WeightObject, KVObject, PrefixObject, Artifact, Checkpoint, PolicyDecision, Observation, Event, AuditRecord。

## Spec/Status 模式

每个对象分离为：Spec（用户期望状态，不可变）和 Status（内核观察状态，仅内核更新）。

## 对象元数据

全局唯一 ID、Schema Version、创建时间、所有者、Namespace、生命周期状态、Generation（CAS）、Resource Version、Trace ID、Audit Metadata。

## 22+ Registry 统一

所有 Registry 使用统一的 `RegistryBase<T>`，提供 CRUD、Watch、Health 操作。UUID v7 标识，Generation CAS 更新，Namespace 隔离。
