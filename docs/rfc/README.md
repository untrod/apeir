# RFCs and architecture decisions

RFCs propose contracts; their presence does not prove an integration or milestone
has passed. The [roadmap](../../ROADMAP.md) records implementation and acceptance.
Kernel RFCs and their translations retain historical/internal protocol names.

Use the [RFC template](0000-template.md) for a concrete problem, authoritative
owners, compatibility, security, failure semantics and evidence requirements.
Existing [architecture decisions](adr/) explain scoped ownership choices.
Read the [canonical architecture](../architecture/README.md) before proposing
new authority, execution or recovery semantics.
