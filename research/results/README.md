- Analysis notebook

- Effect sizes

## Reporting Standards

1. Report negative results and failure cases — not just successes
2. Include raw data, not just summary statistics
3. Pre-register statistical tests before running experiments
4. Document all data exclusions and their rationale
5. Share analysis code for reproducibility
